# 📝 나만의 프롬프트 관리 프로그램 (Prompt Manager)

파편화되어 흩어져 있는 다양한 GenAI 프롬프트를 콘솔(터미널) 환경에서 체계적으로 저장, 분류, 검색할 수 있도록 제작된 Python 애플리케이션입니다.

---

## 🚀 실행 방법

### 요구 환경
* Python 3.10 이상
* Git

### 실행 명령어
터미널에서 프로젝트 폴더 위치로 이동한 뒤 아래 명령어를 입력하여 프로그램을 실행합니다:
```bash
python main.py
📌 주요 기능 목록
프롬프트 추가 (1번): 제목, 내용, 카테고리를 입력받아 새로운 프롬프트를 등록합니다. (제목/내용 공백 방지 유효성 검사 적용)

프롬프트 목록 조회 (2번): 저장된 모든 프롬프트의 번호, 카테고리, 제목, 즐겨찾기(⭐) 여부를 한눈에 출력합니다.

카테고리별 조회 (3번): 원하는 카테고리를 선택하여 해당 카테고리에 속한 프롬프트만 필터링해 확인합니다.

프롬프트 검색 (4번): 키워드를 입력받아 프롬프트의 제목이나 본문에 해당 단어가 포함된 항목을 검색합니다.

프롬프트 상세 보기 (5번): 프롬프트 번호를 지정하여 전체 본문 내용과 상세 정보를 확인합니다.

즐겨찾기 관리 (6번): 번호를 입력하여 자주 쓰는 프롬프트의 즐겨찾기 등록/해제를 전환합니다.

즐겨찾기 목록 (7번): 즐겨찾기(⭐)로 지정된 프롬프트만 모아서 조회합니다.

프로그램 종료 (0번): 프로그램을 안전하게 종료합니다.

📂 지원 카테고리 안내
텍스트 생성: 블로그 글, 이메일, 보고서 등 텍스트 콘텐츠 생성을 위한 프롬프트

이미지 생성: Midjourney, DALL-E 등 고품질 이미지 생성을 위한 프롬프트 및 스타일 키워드

영상 생성: 숏폼 스크립트, 광고 영상 콘티 생성을 위한 지시문

페르소나: 특정 전문가(컨설턴트, 마케터 등) 역할을 부여하는 시스템 프롬프트

자동화: 업무 프로세스 자동화, 데이터 정제 및 뉴스 요약용 프롬프트

기타: 위 분류에 속하지 않는 자유 형식 프롬프트
